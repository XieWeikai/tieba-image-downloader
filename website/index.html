可靠性不是附加功能

程序验证 HTTP 状态、Content-Type、Content-Range 和本地字节数。HTML 错误页不会被误存成图片，服务端忽略 Range 时也不会错误追加。

FAQ

开始之前

它会绕过百度安全验证吗？

不会。需要验证时，它会打开隔离的官方页面，由用户正常完成登录或验证，然后自动继续。

中途关闭后要重新下载吗？

不需要。再次使用同一输出目录运行，完整文件会跳过，符合条件的 .part 文件会从断点继续。

支持哪些系统？

当前正式支持 macOS 12 及以上版本，Release 同时提供 Apple Silicon 和 Intel 构建。

可以只下载楼主图片吗？

可以。在 CLI 使用 --only-author，或直接在 AI 对话中说明“只看楼主”。
